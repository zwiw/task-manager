1. Care este rolul folderului src? 

Folderul src contine codul sursa al aplicatiei (React, JavaScript)

2. Ce reprezintă fișierul App.jsx?

App.jsx este componenta principala a aplicatiei React, in care este definită structura si continutul interfetei.

3. Ce informații sunt păstrate în package.json?

Fișierul package.json pastreaza informatii despre proiect: numele, versiunea, scripturile si dependentele necesare aplicației

4. Ce reprezintă folderul node_modules?

Folderul node_modules contine toate pachetele și bibliotecile instalate prin npm necesare proiectului
